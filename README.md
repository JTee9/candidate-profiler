# Candidate Profiler

Prompt generator for understanding a candidate before outreach or a call. Fill in what you have (name, role, profile URL, pasted profile/resume text), click **Generate prompt**, then paste it into any LLM (ideally with web search on). If you have a resume file, tick the box and attach it in the LLM chat. No API calls, nothing leaves your browser.

Files: `index.html` (form + prompt template), `core.js`, `style.css`.

Deploy: push to the repo root, then Settings > Pages > `main` / root.
